# Luciferium Overhaul (RimWorld 1.6)

Work in progress. Source only until the GitHub Actions build succeeds and in-game testing is complete.

- Configurable Luciferium need fall 0.10–0.30/day (default 0.10 = approximately nine days per 90%-dose).
- Stronger capacities, configurable mood bonus.
- Separate fast injury and slow permanent-injury/addiction healing; biological age reduction.
- Glitterworld medicine and crafting recipes: **not yet implemented**.

Build: GitHub Actions uses .NET SDK, net472 and the Ludeon-authorized NuGet reference package Krafs.Rimworld.Ref 1.6.4871. No original copyrighted game DLLs are committed.

See Source/ and .github/workflows/build.yml. Existing mods should NOT be removed before testing.
